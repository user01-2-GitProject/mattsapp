## 2025-05-20 - Fast-pathing Primitive Operations in Valuation Loops
**Learning:** In the valuation engine, `resolveGradeMultiplier` was called on every single marketplace comp, performing `String().trim().toUpperCase()` and `.includes()` operations on primitive grade values. Combined with dual `RegExp` executions on serial numbers and redundant array sorting after IQR filtering, string manipulation and array allocations dominated CPU time. Fast-pathing primitive string checks, using `indexOf` instead of regex, static cluster definition, and preserving pre-sorted qualified comp arrays doubled engine throughput (>110% speedup on 200-comp datasets).
**Action:** Always check high-frequency array maps in mathematical/analytical engines for inner-loop string transformations or regex operations. Fast-path primitive equality checks and preserve array sort invariants across processing stages.
